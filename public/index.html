03 / MEDIDAS DAX

La definición detrás del indicador

El modelo semántico usa medidas para que las cifras respondan al contexto de filtros. Estas son las reglas principales del proyecto:

Ventas
SUM(fact_sales[sales])
Crecimiento mensual %
(Ventas − Ventas mes anterior) ÷ Ventas mes anterior
Crecimiento interanual %
(Ventas − Ventas año anterior) ÷ Ventas año anterior
Clase ABC
Acumulado ≤ 80% → A · ≤ 95% → B · resto → C

Las medidas completas están en powerbi/medidas.dax del proyecto. La web reproduce estos cálculos sobre SQLite; el ANOVA exploratorio no cambia con los filtros. El PBIX guardado requiere todavía construir y guardar sus visuales analíticos.

04 / USO DEL TABLERO

Cómo leer y explorar

  1. Elige un contexto. Año, país, región y línea filtran los indicadores y gráficos de ventas.
  2. Compara períodos equivalentes. MoM compara el último mes disponible con el mes anterior; YoY compara ese mes con el mismo mes del año previo.
  3. Lee ABC como acumulación. Clientes se ordenan por venta descendente; el porcentaje acumulado determina la clase según 80% y 95%.
  4. Interpreta el mapa con cautela. La burbuja representa ventas por país; las ubicaciones son centroides aproximados, no límites cartográficos.
  5. Usa filtros para segmentar. El conteo de filas indica cuántas líneas quedan en el contexto seleccionado.
05 / VALIDACIÓN ESTADÍSTICA

ANOVA de una vía: ¿todas las medias son iguales?

Comparamos la media de ventas por línea de producto. La observación es una línea de pedido. La hipótesis nula sostiene que todas las medias de producto son iguales.

DECISIÓN · α = 0,05—

Con p < 0,05 se rechaza la hipótesis nula: al menos una media difiere. ANOVA es una prueba ómnibus; no identifica qué pares difieren. Las líneas de una misma orden o cliente podrían no ser independientes, por lo que el resultado es exploratorio y no causal.

06 / QUÉ NO PUEDE CONCLUIRSELOS LÍMITES TAMBIÉN SON PARTE DEL ANÁLISIS
Utilidad

Faltan costos y gastos. Ventas no equivalen a ganancia.

Canal

No hay canal comercial en el origen. Región y territorio no son canal.

Descuento

discount_proxy compara precio unitario y MSRP; no mide una promoción observada.

Moneda y alcance

La moneda no está documentada y la muestra representa una compañía, no todo el retail multinacional.
